High temperature threshold (°C)

Near-object distance (cm)

Distance at or below this value counts as nearby. Can be sent to firmware.

Container height (cm)

Measure from the sensor reference point to the container bottom. Keep the sensor facing down.

About

ESP32 IoT project · Smart Home Resource Hub

SmartHome Resource Hub

A live ESP32 dashboard for monitoring the room, the water tank and the devices in your home, all from one screen.

ESP32DHT11HC-SR04PIRLDRRGB LEDBuzzerST7735 TFT

Current hardware integration

DHT11 temperature/humidity, PIR motion, LDR brightness, HC-SR04 distance and estimated water level, RGB LED, active buzzer, ST7735 TFT, ESP32 Wi-Fi status API, and optional Telegram alerts in firmware.

Not currently measured / controlled

Power/energy and water flow need compatible sensors. Fan and pump controls need physical driver wiring and matching firmware. The dashboard never fabricates those values.
